# Game icons

Original game icons from the games’ Steam Community pages, bundled for offline identification in the game-binding dialog. Exact source URLs and SHA-256 hashes are in `sources.json` in the repository and `licenses/Game-icons.sources.json` in the app package.

Game names, logos and artwork belong to their respective owners. Inclusion identifies supported games and does not imply endorsement or affiliation. These third-party images are not covered by SherpaAxis’s source-code license.
